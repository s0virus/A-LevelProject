# A-LevelProject
2D Physics based platform game coded in C# using Monogame Framework

The game is an infinitely generated side scrolling platform game where the players objective is to get the highest possible score.
The player can scale obstacles by jumping, wall bouncing, and air dashing.
Enemies can be killed by aiming with the cursor and shooting them.
Enemies health pool increases as the distance increases but the player can upgrade their gun stats in the 'Armory' between runs.
Each time the player dies without achieving a high score, they lose a life. Lose 3 lives and the game resets.
